# v1.2.2 — Stable storefront rollback

This hotfix restores the public runtime files from commit `ce0bab662435a5faebb7327329300810fe1d6297`, the last version reported as stable before v1.2.

Restored public runtime:
- `.env` with Supabase public/project variables used by Vite/SSR builds.
- `src/routes/index.tsx` stable Home implementation.
- `src/routes/__root.tsx` stable root shell/bootstrap.
- `src/lib/cart-store.ts` stable cart runtime.

The v1.2 admin modules, database migrations, intelligence, pricing, performance and Home Builder files remain in the repository. This rollback intentionally isolates them from the public storefront until they are reintroduced incrementally with regression tests.

Reason: v1.2 simultaneously replaced the Home implementation and removed the build-time Supabase public environment file. That changed two critical startup dependencies at once and made production diagnosis unreliable. v1.2.2 restores the known-good public path first.
